# Contoh Paket Setup ZRF (macro Route B) — teks lengkap

Diperbarui: 2026-10-21 (rev: HULL-BODY, Dummy per disiplin, urutan grup baru). Versi teks dari `ZRF-SETUP-PACKAGE.zip` (file binary tidak bisa disimpan sebagai doc project). Dipakai sebagai **contoh nyata** untuk materi belajar E3D Administration.

**Catatan untuk pembaca/chat lain:**
- Macro di bawah adalah hasil kerja project ZRF (E3D 3.1.8.1 / Administration 2.1.0.1).
- Command Admin (`CREATE`, `SET MDB`, `ADD`, `CURRENT`) sesuai dokumentasi AVEVA. `NEW SITE ... DB` sudah dites dan berhasil; `NEW ZONE` belum dites di ZRF. Status per fakta ada di `e3d-admin/fakta-terverifikasi-e3d-admin.md`.
- Baris yang diawali `$*` adalah komentar.
- Isi semua disiplin berpola sama. Di sini ditampilkan lengkap untuk **Piping (02-L-ZRFPIP)**.

## 2. 00-README.txt

```
ZRF (ZR FLNG) - E3D SETUP PACKAGE (start from zero)
Generated 2026-10-21. Full guide: ZRF-E3D-Register.xlsx, sheet 'Setup Steps'.

PREPARATION (Admin, SYSTEM)
 - Delete all old ZRF DBs. Check MDB-ZRF is empty and no old ZRF DB files remain in the project folder.
 - Nobody else logged in to ZRF.

STEPS (command macros only)
 00-TEAMS -> per discipline: B1 (Admin) -> B2 sites (Design) -> B3 zones (Design)

ORDER: disciplines 01 -> 10 (MDB positions follow on), then 90-REFERENCE.
Admin steps before Design steps; re-enter DESIGN after each Admin step.
99-FIXUP only if the MDB order is wrong.

KNOWN ISSUE: random '(43,41) Unable to open DB ... MCD:6 The handle is invalid' while creating DBs.
Note the DB, delete it in Admin if broken, recreate it, continue.
```
